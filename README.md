# SRE contribution tracker

Living list of open-source **SRE / reliability / ops** projects that regularly have contribution opportunities (`good first issue`, `help wanted`, and similar).

Maintained for [niuguy](https://github.com/niuguy). Companion to [gocontrib](https://github.com/niuguy/gocontrib).

## How to use

1. Browse [`PROJECTS.md`](PROJECTS.md) for the tracked repos.
2. Jump into [`OPPORTUNITIES.md`](OPPORTUNITIES.md) for concrete open starter issues.
3. Add or refresh entries when you find a new project worth watching.
